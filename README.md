# Élixir du Terroir — Secrets de la nature

Site vitrine réalisé pour **Élixir du Terroir**, marque de produits naturels.

**En ligne : [alexcruss.github.io/ELIXIRDUTERROIR](https://alexcruss.github.io/ELIXIRDUTERROIR/)**

## Ce que fait le site

- Présente la marque et ses produits naturels
- Raconte l'origine des produits et leurs bienfaits
- Oriente les visiteurs vers la commande ou le contact

## Technique

Site statique en HTML et CSS, responsive, déployé sur GitHub Pages par un workflow GitHub Actions.
